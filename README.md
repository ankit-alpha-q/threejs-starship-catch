# Starship Booster Catch · Three.js

A tower, two chopsticks and a falling booster, all in Three.js.

**Live demo:** https://ankit-alpha-q.github.io/threejs-starship-catch/

Built step by step on the MahaDev YouTube channel. Everything is in [`starship.js`](./starship.js).

## Run it
Any static server works, for example:
```
npx serve .
```

## Make it yours
- Slower landing: 24 → 40
- Miss the catch: booster x 1.3 → 2.6
- Daytime: background #7fa8d8
